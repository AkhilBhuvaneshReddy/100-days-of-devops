## 📌 About This Challenge

I'm completing **100 Days of DevOps** through KodeKloud and documenting my hands-on journey here.

The goal is not simply to complete 100 tasks, but to understand DevOps concepts through practical work, troubleshooting, automation, and projects.

## 🎯 Goals

- 🐧 Strengthen Linux fundamentals
- 🔀 Master Git and GitHub
- 🐳 Learn Docker and containerization
- ☸️ Build practical Kubernetes skills
- 🔧 Learn CI/CD and Jenkins
- ⚙️ Learn Ansible automation
- 🏗️ Learn Terraform and Infrastructure as Code
- ☁️ Develop practical AWS skills
- 📊 Learn monitoring and observability
- 🔐 Understand DevSecOps practices
- 🛠️ Build real-world DevOps projects
- 💼 Become interview-ready for DevOps roles
